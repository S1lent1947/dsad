Plugin pentru PyCharm

        
Același generator, direct în PyCharm. Citește fișierele CSV și PDF-ul subiectului din proiect, scrie main.py și îl pornește.

        Descarcă pluginul (dsad-pycharm.zip)
        
Pentru PyCharm 2022.3 sau mai nou. Are nevoie de internet: panoul încarcă acest site.

      

      

        

          
Instalare

          
    
            
  1. Descarcă dsad-pycharm.zip. Nu îl dezarhiva.
    2. 
            
  2. În PyCharm deschide File → Settings → Plugins (Ctrl+Alt+S).
    3. 
            
  3. Apasă rotița de lângă tab-ul Installed și alege Install Plugin from Disk…
    4. 
            
  4. Alege fișierul descărcat, apoi repornește PyCharm dacă ți se cere.
    5. 
          

        

        

          
Folosire la test

          
    
            
  1. Pune în proiect fișierele de la test: CSV-urile (de preferat în data_in/) și PDF-ul cu subiectul.
    2. 
            
  2. Deschide panoul DSAD din bara din dreapta.
    3. 
            
  3. Verifică cerințele găsite. Dacă PDF-ul nu e în proiect, lipește textul subiectului.
    4. 
            
  4. Apasă Scrie main.py în proiect și rulează. Rezultatele apar în data_out/, iar în panou vezi ✓ sau ✗ pentru fiecare cerință.
    5. 
          

          
Dacă main.py există deja, pluginul te întreabă înainte să-l înlocuiască.
